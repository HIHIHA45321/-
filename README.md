# 📅 Расписание колледжа ККОТИП

Веб-приложение для просмотра расписания занятий. Работает на любом устройстве через браузер.

🔗 **Ссылка на сайт:** [ВСТАВЬТЕ ССЫЛКУ]

---

## 👥 Для пользователей

### Как войти
На главной странице три варианта входа:

**👁 Гость** — просмотр расписания всех групп без регистрации

**🎓 Студент** — регистрация с выбором группы, личное расписание и заметки к парам

**👨‍🏫 Преподаватель** — вход по выданному логину и паролю, все свои пары на неделю и заметки

### Заметки
Авторизованные пользователи могут оставлять личные заметки к каждой паре.
Заметки видны только вам — никто другой их не видит.

## 🔧 Для администратора

### Открыть панель управления
- **На компьютере:** `Alt + P`
- **На телефоне:** долгое нажатие (1.5 сек) на иконку 📅 на главном экране

### Что можно делать в панели
- 📂 **Загрузить расписание** — выбрать Excel файл (.xlsx), данные обновятся у всех пользователей
- 👨‍🏫 **Создать преподавателя** — ввести ФИО (как в расписании), логин и пароль
- 🔑 **Сбросить пароль** — указать логин пользователя и задать новый пароль

### Формат Excel файла
- Названия групп в строке заголовка (например: ИС25-1-1, М25-1)
- День недели в первом столбце (Понед., Вторн. и т.д.)
- Номер пары во втором столбце
- Предмет, преподаватель и кабинет в столбцах группы

## 🛠 Технологии

- **HTML + JavaScript** — одностраничное веб-приложение
- **Firebase Realtime Database** — облачное хранилище данных Google, расписание обновляется у всех в реальном времени
- **XLSX.js** — парсинг Excel файлов прямо в браузере
- **Web Crypto API (SHA-256)** — хэширование паролей, пароли в открытом виде нигде не хранятся

---

## 📋 Возможности

- Три режима: гость, студент, преподаватель
- Авторизация с защищённым хранением паролей
- Личные заметки для каждого пользователя
- Автоматическое определение замен (выделяются красным)
- Скачивание расписания группы в Excel
- Адаптивный дизайн для телефона и компьютера
- Данные сохраняются в облаке и доступны всем без установки приложения
